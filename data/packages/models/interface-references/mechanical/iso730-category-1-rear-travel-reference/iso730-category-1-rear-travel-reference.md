# ISO 730 Category 1 rear linkage travel gauges

**Catalogue draft ID** `iso730-category-1-rear-travel-reference`. Revision 1.

[Native DWG 2018](iso730-category-1-rear-travel-reference.dwg), SHA-256 `f8a4737c45083e101f6554536141f83e0e2b3b840e59a46d60f13b2ae602ca1d`.

## Geometry

Separate native CAD gauges for rear linkage lift and adjustment. Minimum powered movement 610 mm. Minimum transport height 820 mm.

X gauge station, Y forward, Z up. Each independent check has its own zero..
X offsets separate the individual gauges for display.

- Maximum lowered height 200 mm.
- Minimum levelling adjustment 100 mm.
- Minimum powered movement 610 mm.
- Minimum transport height 820 mm.
- Minimum tyre clearance radius 100 mm.
- Minimum upper mast adjustment height 508 mm.
- Maximum lower mast adjustment height 200 mm.
- Minimum torsional free float 60 mm.
- Rearward mast pitch limit 5° from vertical.
- Forward mast pitch limit 5° from vertical.
