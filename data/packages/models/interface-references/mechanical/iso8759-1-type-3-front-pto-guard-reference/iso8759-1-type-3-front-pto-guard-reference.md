# ISO 8759-1 front PTO type 3 guard clearance reference

**Catalogue draft ID** `iso8759-1-type-3-front-pto-guard-reference`. Revision 1.

## Geometry

Native 3D lines marking the shield aperture and clearance dimensions. Width p is 360 mm, height m is 150 mm above and below the PTO axis and the forward offset n is 100 mm.

X right, Y forward, Z up. Origin on axis at PTO shaft-end plane..

Minimum axial span a is 95 mm. Minimum aperture depth k below the axis is 80 mm.
The dimensioned boundary guides mark 30° lateral, 50° upper and 45° lower minimum angles.
Maximum radii SRr and r are 90 mm and 90 mm. The radius limits constrain the selected guard profile.
The nominal source tolerances are ±5 mm for m and n and ±10 mm for p.
The separate guard anchorage uses Figure 1 and ISO 8759-1 Clause 4.3.
ISO 8759-3:2018 clause 4.2: anticlockwise viewed from front.
Table 1 permits a separate flexible shield width p of 295 mm.
