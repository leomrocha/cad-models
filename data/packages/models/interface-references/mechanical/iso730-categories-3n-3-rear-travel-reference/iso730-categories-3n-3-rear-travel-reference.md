# ISO 730 Categories 3N and 3 rear linkage travel gauges

**Catalogue draft ID** `iso730-categories-3n-3-rear-travel-reference`. Revision 1.

[Native DWG 2018](iso730-categories-3n-3-rear-travel-reference.dwg), SHA-256 `3667406369e2fa860be4e96bfaab025d820f92c05b24beefd32d245c09629373`.

## Geometry

Separate native CAD gauges for rear linkage lift and adjustment. Minimum powered movement 735 mm. Minimum transport height 1065 mm.

X gauge station, Y forward, Z up. Each independent check has its own zero..
X offsets separate the individual gauges for display.

- Maximum lowered height 230 mm.
- Minimum levelling adjustment 125 mm.
- Minimum powered movement 735 mm.
- Minimum transport height 1065 mm.
- Minimum tyre clearance radius 100 mm.
- Minimum upper mast adjustment height 660 mm.
- Maximum lower mast adjustment height 230 mm.
- Minimum torsional free float 75 mm.
- Rearward mast pitch limit 5° from vertical.
- Forward mast pitch limit 5° from vertical.
