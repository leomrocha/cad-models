# ISO 8759-4 Category 4N front transport linkage reference

**Catalogue draft ID** `iso8759-4-category-4n-front-linkage-reference`. Revision 1.

[Native DWG 2018](iso8759-4-category-4n-front-linkage-reference.dwg), SHA-256 `5795ae356ee34e3a692ccaadb472f65f1764564bfd8ce6c6bc4c2273e90a219e`.

## Geometry

Nominal pin-interface solids. Lower shoulder span 952 mm, mast height 685 mm, upper pin diameter 45 mm, lower pin diameter 50.8 mm. Transport pitch limit poses at 8° and 12° and a 250 mm tyre-clearance datum.

Millimetres. X transverse, Y longitudinal, Z up. The origin is midway between the lower implement shoulder planes. The upper and lower pin axes run along X.

Upper axial reference length 65 mm represents the Table 4 minimum yoke internal width.
Each lower reference runs from its implement shoulder to the 68 mm minimum linchpin-hole station.
The solids represent nominal interfaces used for placement. Tractor ball joints, mechanism travel and manufacturing features have separate geometry.

## Source limits

The source tolerance for lower span and mast height is ±1.5 mm.
Upper and lower pin diameters in the DWG are nominal values at the upper size limit.
The source gives 920.5 ±1.5 mm for the separate ISO 11001-1 U-frame coupler case.

## Front transport reference

The 8° and 12° upper pin positions are separate limit poses about the same lower axis. The CAD convention tilts the upper point toward the front for both poses.
The longitudinal datum measures 250 mm from the lower hitch axis toward the straight-ahead tyre position.
Clause 4(d) gives 375 mm minimum transport height for track settings below 1,150 mm or for low-clearance tractors.
Clause 4(c) gives Category 4N a 1000 mm minimum transport height. The vertical datum from Z = 0 represents that height.
