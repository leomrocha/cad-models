# ISO 730 Category 1N rear linkage travel gauges

**Catalogue draft ID** `iso730-category-1n-rear-travel-reference`. Revision 1.

[Native DWG 2018](iso730-category-1n-rear-travel-reference.dwg), SHA-256 `2456ea87dbb436a2eb0a1a4a595a6cad784a1835aaa82eaed388e45588878501`.

## Geometry

Separate native CAD gauges for rear linkage lift and adjustment. Minimum powered movement 610 mm. Minimum transport height 600 mm.

X gauge station, Y forward, Z up. Each independent check has its own zero..
X offsets separate the individual gauges for display.

- Maximum lowered height 200 mm.
- Minimum levelling adjustment 75 mm.
- Minimum powered movement 610 mm.
- Minimum transport height 600 mm.
- Minimum tyre clearance radius 90 mm.
- Minimum upper mast adjustment height 420 mm.
- Maximum lower mast adjustment height 200 mm.
- Minimum torsional free float 60 mm.
- Rearward mast pitch limit 10° from vertical.
