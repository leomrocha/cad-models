# ISO 730 Category 4N rear implement hitch-point interface

**Catalogue draft ID** `iso730-category-4n-rear-implement-reference`. Revision 1.

[Native DWG 2018](iso730-category-4n-rear-implement-reference.dwg), SHA-256 `530581ec0abe348975781d399d94c566e21803678ab8a5b0dbda07c908d1859f`.

## Geometry

Three nominal pin-interface solids. Lower shoulder span 952 mm, mast height 685 mm, upper pin diameter 45 mm, lower pin diameter 50.8 mm.

Millimetres. X transverse, Y longitudinal, Z up. The origin is midway between the lower implement shoulder planes. The upper and lower pin axes run along X.

Upper axial reference length 65 mm represents the Table 4 minimum yoke internal width.
Each lower reference runs from its implement shoulder to the 68 mm minimum linchpin-hole station.
The solids represent nominal interfaces used for placement. Tractor ball joints, mechanism travel and manufacturing features have separate geometry.

## Source limits

The source tolerance for lower span and mast height is ±1.5 mm.
Upper and lower pin diameters in the DWG are nominal values at the upper size limit.
The source gives 920.5 ±1.5 mm for the separate ISO 11001-1 U-frame coupler case.
